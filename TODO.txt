## Agent / query conventions for anime_mal

- my_status = 'plan_to_watch' entries should usually be EXCLUDED by default
  when answering general questions about "my anime" (recommendations, stats,
  browsing, etc.) — plan_to_watch means I haven't watched it, so it's not
  representative of taste/history. Only include plan_to_watch entries when
  the question is specifically about the plan-to-watch list itself.

- Know which columns are indexed (see schema/anime_mal_indexes.sql) and bias
  query shape toward filtering/sorting on those when a question could
  reasonably be answered either way. Currently: my_status, start_date, mean,
  my_start_date.
